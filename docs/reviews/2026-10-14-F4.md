# F4단계 검토 (다국어 관리 화면)

결과: 승인

- 경로 `/mdm/i18n`, `?ns=` 쿼리, 좌우 분할, 메시지 Drawer 탭, 빈 번역 제외, 키·버전 읽기 전용이 지시서대로 구현됨.
- lint, antd lint, tsc 통과. 테스트 26파일 99개 통과, `flow.test.tsx` 20개 3회 반복 통과. `build`, `build:platform` 정상(플랫폼 빌드에 화면 없음).
- 공통코드 화면 소스와 플랫폼 라우트는 수정하지 않음.

검토 사항: 메시지 목록 응답의 `translations`가 비어 있어 표의 "번역 상태" 열이 `—`만 표시됨. 행마다 단건 조회는 요청이 과다하므로 프런트에서 풀지 않고, 백엔드 8.7단계에서 목록 응답에 `translatedLanguageCodes`, `missingLanguageCodes`, `translationStatusCodes`를 추가하기로 함.

사용자 직접 확인: 실제 서버 반영, 서버 오류 문구 표시, 좁은 화면 배치, 전체 사용감 (`frontend/doc/f4-manual-check.md`).
