## 문제
- **관리자 잠금이 자동으로 풀린다.** 보고서 질문대로 관리자 잠금도 `locked_datetime=지금` 이라 `LOCK_MINUTES` 뒤 맞는 비밀번호로 로그인하면 `LoginLockRules` 가 잠금을 푼다. 관리자가 건 잠금이 사실상 일시 잠금이 된다. 수정 방향: 관리자 잠금은 `locked_datetime=NULL` 로 두어 "해제 시각 없는 잠금"으로 구분하고, 자동 해제는 `locked_datetime` 이 있는 잠금(실패 횟수 초과)에만 적용한다. → 9.3 A절.

## 확정한 가정
- API `roleCode` 는 2~50자(DB 는 1자 이상). `personPk` null 은 연결 해제이며 모든 계정 유형에 허용. `userCount` 는 사용 중 사용자의 현재 유효 부여만.
