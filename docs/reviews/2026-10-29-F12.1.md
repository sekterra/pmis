# F12.1 검토 (2026-10-29)

판정: 승인.

- UserMenu 의 Dropdown 자식을 하나로 감싸 로그인 후 오류를 해결했다(사용자 확인). 같은 패턴 전수 조사 결과 다른 곳은 없다.
- 실제 antd Dropdown 으로 렌더하는 회귀 테스트와 레이아웃 스모크 테스트(플랫폼, 테넌트)가 추가되었다. ProLayout 은 vitest 에서 로케일 모듈 문제로 못 쓰고 Layout 합성으로 대체했다는 한계는 수용한다.
- 진입 화면의 StrictMode 이중 실행 문제는 모듈 수준 약속(promise)으로 해결했다.
- 개발 환경 테넌트 코드 전달 확인 표가 명확하다(토큰의 tenant 클레임으로 충분, 프록시는 기존 헤더를 덮어쓰지 않음).
- 메뉴 번역 경고 제거, 기록 화면 흐름 테스트 2개, 개발 모드 오류 메시지 표시, UTF-8 diff 모두 지시대로.
- 전체 테스트 시간이 약 430초로 늘었다. 화면 이전 단계에서 ProTable 을 실제로 렌더하면 더 늘 수 있어, 별도 속도 개선 단계를 F14 이후에 둔다.
