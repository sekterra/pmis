# F10단계 검토 (2026-10-29)

대상: `docs/reports/F10.md`, `F10.diff` (시작 커밋 3cd5e7c, 구현 커밋 13e456d), 핵심 코드 `matrix.ts`, `rules.ts`, `rolesQuery.ts`.

## 결론

승인(자동 검증 기준). lint, antd lint, tsc, 테스트 200개, build 가 통과했다. F9 보완(소속 조회 의존성)도 반영되었다. 화면 직접 확인은 보류 상태다.

## 좋은 점

- 권한 표 변환·연동·변경 감지가 `matrix.ts` 의 순수 함수로 분리되어 테스트된다. 비READ 켜기 → READ 자동, READ 끄기 → 나머지 끄기, 메뉴 전체 토글이 지시서대로 구현되었다.
- 저장 본문은 켜진 `permissionCode` 전체이고(교체 방식), `ROLE.READ_REQUIRED` 의 메뉴 행 표시와 변경 중 탭 이동 확인이 있다.
- 오류 문구가 처음부터 번들 키를 쓰고 서버 `errorMessage` 가 우선이다.
- 새 경로 접두사 `/access` 가 플랫폼 영역에서 막힌다.

## 알아둘 점

- 전체 테스트가 약 299초로 늘었다(F8 262초 → F9 262초 → F10 299초). 화면 흐름 테스트가 파일당 약 20초이다. F11 보고서에 파일별 소요 시간 분석을 요청했고, 그 결과로 테스트 속도 개선 작업을 따로 잡는다.
- 역할 화면 한 개의 흐름 테스트가 4개뿐이다. 읽기 전용 표의 모든 경로(TENANT_ADMIN, 사용 중지 역할, UPDATE 권한 없음)를 테스트가 다루는지는 수동 확인에서 한 번 더 본다.
- 보고서 e절의 "초안은 버튼을 숨긴다" 문장은 지시서가 읽기 전용 표로 바꾼 것을 뜻한다. 현재 구현은 지시서대로다.
