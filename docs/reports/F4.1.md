## c. 핵심 코드

번역 상태 열 (`frontend/src/pages/mdm/i18n/index.tsx`): 세 필드가 모두 없으면 `—`. 있으면 번역 태그, 누락은 `color="warning"`, 누락 배열이 비면 완료, 상태 코드는 뒤에 붙인다. `getMessage`는 부르지 않는다.

언어 목록 쿼리 (`languageQuery.ts`): `useYn`이 Y/N일 때만 붙인다. 국가 목록은 `managed: true`, page 기본 1, size 기본 20이고 정렬 필드는 `nationCode`, `nationName`, `sortOrder`, `nationPk`만 남긴다.

기본 언어 확인 (`language/index.tsx`): `body.defaultLanguage && !editingLanguage?.defaultLanguage`일 때만 확인창을 띄우고, 문구는 `기존 기본 언어가 해제된다`. 사용 중지 버튼은 `defaultLanguage`가 참이면 숨긴다.

권한 (`permission.ts`): `grantLanguage`는 항상 true. F5에서 `can('I18N', action)`으로 바꾼다.

## e. 가정, 질문, 알려진 한계, 지시에서 벗어난 점

- 질문: 국가 탭의 keyword·useYn 필터는 합의 도식에 있지만 관리 목록 API에 없다. 그 부분만 구현하지 않았다.
- 한계: 언어 목록 캐시 무효화 함수가 없다. 로그인·헤더 선택은 다음 `loadPublicI18n`(앱 시작 또는 로케일 변경) 때 바뀐다. F4 번역 언어 목록은 그 화면이 다시 마운트될 때 `fetchLanguages`로 다시 받는다.
- 가정: 새로 등록하면서 기본 언어로 저장할 때도 확인창을 띄운다. 이미 기본인 행을 수정할 때는 띄우지 않는다. 403은 서버 문구를 버리고 로컬 안내만 쓴다. 저장 버튼은 antd 로딩이 두 번째 클릭을 삼킨다.
- 지시에서 벗어난 점: 없음
