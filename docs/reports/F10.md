## c. 핵심 코드

권한 연동은 `src/pages/access/role/matrix.ts`의 `setGranted`다. READ가 아닌 기능을 켜면 같은 메뉴 READ를 켜고, READ를 끄면 그 메뉴의 칸을 모두 끈다. 저장은 켜진 `permissionCode`만 `replaceRolePermissions`로 보낸다.

## e. 가정, 질문, 알려진 한계

- 초안은 테넌트 관리자 권한 버튼을 숨긴다. 지시서는 표를 읽기 전용으로 보이고 이유를 안내한다. 지시서를 따랐고 `frontend/doc/f10-wireframe.md`에 적었다.
- 메뉴 이름은 API `menuName`이다. 기능 열 이름은 로컬 문구이고, 키에 없는 코드는 코드 그대로다.
- 부모 그룹은 서버 `menus/my`의 `parentMenuCode`를 쓴다. 화면에서 그룹 코드를 가정하지 않았다.
- 권한 조회에 `granted`를 보내지 않는다. 이름 언어는 기존 요청의 `Accept-Language`를 따른다.
- 역할 수정 필드는 모두 화면에 있다. 빈 설명은 null이다.
- Drawer 너비는 회사 화면과 같은 `size="large"`다.
- 전체 테스트가 약 299초로 늘었다. 역할 흐름 파일은 약 21초다. `vitest.config.ts`는 바꾸지 않았다.
- 사용자가 직접 볼 항목은 `frontend/doc/f10-manual-check.md` 맨 위에 있다.
