## c. 핵심 코드

- 감사자: `CurrentTenantUser.getCurrentAuditor`는 `typ=tenant-user`인 JWT의 `sub`만 숫자 PK로 읽는다. 플랫폼 토큰과 인증 없음은 빈 값이다.
- 부서 이동: `DeptService.relocate`가 `dept_path = 새접두사 || substring(dept_path from 시작)`과 `level_no + delta`를 한 문장으로 갱신한다. 조건은 같은 경로이거나 `접두사/%`다.
- 주 소속: `PrimaryAssignmentPolicy.becomesPrimary`는 다른 현재 소속이 없으면 `Y`로 두고, 이후 `Y` 요청만 기존 주 소속을 내린다. 종료 API는 다른 행의 `primaryYn`을 바꾸지 않는다.
- 코드 검사: `CodeQueryService.isCurrentlyUsable`이 사용 중 그룹·코드와 `TenantClock.today()` 유효기간을 본다.

## e. 가정, 질문, 알려진 한계

- 질문: `company_code`를 `^[A-Z0-9_-]{1,50}$`로 받았다. ERD 설명에는 길이 50과 유니크만 있다.
- 가정: 목록 `useYn` 생략은 7단계와 같이 사용 중지를 포함한다. 부서 트리만 날짜가 없으면 오늘 기준 사용 중 부서다. `includeClosed=true`이면 오늘 유효기간 안의 중지 부서도 포함한다.
- 가정: 국가가 없거나 사용 중이 아니면 `COMMON.VALIDATION_FAILED`와 `fieldErrors(nationCode)`다.
- 가정: 사원번호 유니크는 V5다. `use_yn='Y'`이고 값이 있을 때만 유일하고 종료일은 조건이 아니다.
- 가정: 복구 권한은 `UPDATE`다. 메뉴·권한·`DEPT_CHANGE_TYPE` 시드는 이미 있어 추가하지 않았다.
- 한계: 과거 조직도는 재구성하지 않는다. 주 소속 조회 횟수는 목 검증이고 SQL 통계는 없다. 401/403은 보안 필터가 있는 통합 테스트에서 확인했다.
