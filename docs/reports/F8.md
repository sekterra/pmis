## e. 가정, 질문, 알려진 한계

- 합의 와이어프레임은 소속 인원 행을 사람 화면으로 보낸다. F8은 그 화면이 없어 행 이동을 만들지 말라고 해서 구현하지 않았다. `doc/f8-wireframe.md`에 적었다.
- 코드 목록은 `CommonCodeService.toResponse`가 언어별 번역을 모두 싣고, `codeOptionLabel`이 현재 언어를 고른다. 언어 변경 때 캐시를 비우지 않는다.
- 이력·소속 인원 표는 회사 화면과 같은 antd `Table`이다.
- 부서 코드 API에는 정규식이 없다. 폼은 길이 1–50만 본다.
- 이력의 상위 부서는 PK만 표시한다. 이름 조회 API가 없다.
- 수정 때 화면에 없는 `description`을 상세 값으로 다시 보낸다. 등록 때는 보내지 않는다.
- 회사 Select는 사용 중 회사 첫 페이지(size 200)만 담는다.
- 종료는 본문 없이 DELETE 한다. 서버가 종료일을 오늘로 둔다.
- 이름 번역은 F7 `NameTranslations`를 재사용했다. 공통코드 화면은 수정하지 않았다.
- 트리는 `motion={false}`, `virtual={false}`다.
- 전체 테스트를 파일 병렬로 돌리면 화면 흐름이 시간 제한에 걸렸다. `fileParallelism: false`, `testTimeout: 30000`으로 바꿨다.
- 플랫폼과 테넌트는 빌드가 하나다. 백엔드는 수정하지 않았다.
