# 공통코드 관리 화면 와이어프레임

경로 `/mdm/common-code`. 테넌트 앱만. 플랫폼 콘솔 라우트에는 없다.

승인된 구성(좌우 분할, 폼 안 언어 탭, 이력 Drawer, 계층형은 트리 테이블)과 같다. 명세에 없는 필드는 넣지 않는다.

```
페이지 제목: 공통코드
[권한 없음 안내]  ← 서버 403 AUTH.FORBIDDEN 일 때만

┌ 코드그룹 ─────────────────────┐  ┌ 공통코드 ──────────────────────────┐
│ 검색 [keyword        ]         │  │ (그룹 미선택) 그룹을 선택하세요.    │
│ 솔루션 [solutionCode ]         │  │                                    │
│ 사용 [전체/Y/N] [조회]         │  │ 또는 그룹 선택 후:                  │
│ [그룹 등록]                    │  │ 코드 / 이름 / 계층형 / 값 길이      │
│ 표: 코드* 이름* 솔루션* 정렬*  │  │ 검색 [keyword] 사용 [전체/Y/N]     │
│     사용여부  [수정][삭제|복구]│  │ [코드 등록]                        │
│ 페이지 20                      │  │ 표: 코드값* 이름* 정렬* 사용여부   │
│ 사용 중지 행은 흐리게          │  │     [수정][삭제|복구][이력]        │
└────────────────────────────────┘  │ 계층형이면 트리. 아니면 일반 표.    │
                                    │ 페이지 20                           │
                                    └────────────────────────────────────┘
좁은 화면: 위 그룹, 아래 코드
선택 그룹은 URL ?group=코드
* 정렬 가능한 열은 명세 화이트리스트만
```

등록/수정은 오른쪽 Drawer.

```
그룹 Drawer
[기본 정보] [언어별 이름]
기본: 그룹코드(수정 시 읽기 전용), 솔루션, 이름, 설명, 계층형, 코드값 길이, 정렬
언어: 지원 언어 한 행에 이름·설명. 이름이 빈 언어는 요청에서 뺀다.

코드 Drawer
[기본 정보] [언어별 이름]
기본: 코드값(수정 가능), 기본 이름, 상위 코드(계층형만, 자신과 하위 제외),
      시작일~종료일, 정렬, 확장속성 1~5, 변경 사유
```

삭제 확인창에는 사용 중지(use_yn=N)라고 적는다. 사용 중지 행만 복구.

이력 Drawer: 변경 시각, 유형(C/U/D 문구), 사유, 변경 사용자 pk. 행을 펼치면 변경 전/후 key-value. 사용자 이름 API는 없으므로 pk만.
