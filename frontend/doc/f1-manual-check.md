# F1 수동 확인

백엔드와 테넌트는 이 문서에서 준비하지 않는다. 값은 적지 않고 환경변수 이름만 적는다.

1. `frontend`에서 `npm install` 후 `npm run dev`로 개발 서버를 띄운다.
2. 환경변수 `DEV_BACKEND_URL`에 백엔드 주소를 두고, 로컬에서 테넌트를 구분하려면 `DEV_TENANT_CODE`를 둔다. `APP_MODE`는 `tenant`다. 운영 빌드에는 이 값들이 들어가지 않는다.
3. 로그인: 아이디와 비밀번호만 있는 카드에서 로그인한다. 실패하면 계정과 비밀번호를 구분하지 않는 문구가 한 번 보인다.
4. 강제 변경: `passwordChangeRequired`인 계정은 비밀번호 변경 화면만 열린다. 현재 비밀번호, 새 비밀번호, 확인을 넣고 변경하면 환영 화면으로 간다. 서버 정책 오류는 해당 필드에 그대로 보인다.
5. 세션 복구: 로그인한 뒤 브라우저를 새로고침한다. 다시 로그인하지 않아도 환영 화면이 유지된다. 개발자 도구의 localStorage와 sessionStorage에 Access 토큰이 없어야 한다.
6. 다중 탭 로그아웃: 같은 사이트를 두 탭에서 연 뒤 한쪽에서 로그아웃한다. 다른 탭도 로그인 화면으로 간다.
7. 언어 변경: 로그인 카드 아래 또는 헤더의 언어 선택을 바꾼다. 문구가 바뀌고, 서버 번들을 받지 못해도 화면의 기본 문구는 남는다.
