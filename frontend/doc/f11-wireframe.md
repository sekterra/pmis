# F11 사용자 화면

기준은 `users-roles-wireframe.md` 1절·2절과 F11 지시서다. 지시서가 더 구체적인 곳은 지시서를 따른다.

## 목록

- 검색: 로그인 아이디·사람 이름, 상태(`USER_STATUS`), 계정 유형(`ACCOUNT_TYPE`), 역할, 사용 여부. 사용 여부 전체는 파라미터를 보내지 않는다.
- 열: 로그인 아이디, 사람, 계정 유형, 상태(문구와 색), 역할, 마지막 로그인, 비밀번호 변경 필요, 사용 여부, 작업.
- 역할은 코드 → 이름이다. 세 개를 넘으면 `외 N`. `ROLE:READ`가 없으면 코드를 그대로 보인다.
- 정렬 열: 로그인 아이디, 상태, 마지막 로그인. 생성일 정렬은 초안에 있으나 이 단계 열에는 없다.
- 사용 중지이거나 탈퇴인 행은 흐리게 한다. 행을 누르면 Drawer.

## 등록

- 로그인 아이디(3~100자, 영문·숫자·`._@-`), 소문자로 저장된다는 안내, 논리 삭제한 아이디는 다시 쓸 수 없다는 안내.
- 계정 유형 기본 `NORMAL`. 사람 검색은 사용 중 사람을 `keyword`로 찾고 표시는 `이름 (이메일)`. 이미 연결된 사람은 서버가 거절하고 그 문구를 사람 칸에 둔다. 초안의 "계정이 없는 사람 우선"은 쓰지 않는다.
- 언어 기본 `ko-KR`. 시간대는 `Intl.supportedValuesOf('timeZone')`, 없으면 `Asia/Seoul`을 포함한 짧은 목록. 기본 `Asia/Seoul`.
- 초기 역할은 사용 중 역할 다중 선택. `TENANT_ADMIN`을 고르면 경고를 보인다. `ROLE:READ`가 없으면 선택을 숨기고 안내 한 줄을 보인다.

## 임시 비밀번호

- 등록과 초기화가 같은 모달이다. 비밀번호는 크게, 고정폭, 숨기지 않는다. 만료 시각과 복사 버튼이 있다. 복사가 실패하면 선택해서 복사하라는 안내를 보인다.
- 바깥 클릭과 ESC로는 닫히지 않는다. 닫으면 상태에서 바로 지운다. 닫힌 뒤 Drawer는 그 사용자의 수정 모드다.

## 상세

- 탭은 기본 정보와 역할. 로그인 아이디·계정 유형·상태는 읽기 전용. 수정 본문은 사람, 언어, 시간대, 설명만이다.
- 잠금 종류, 실패 횟수, 비밀번호 변경일·만료일, 마지막 로그인, 생성·수정 정보를 읽기 전용으로 보인다.
- 동작: `ACTIVE`는 잠금·휴면, `LOCKED`는 잠금 해제, `DORMANT`는 휴면 해제. 탈퇴이거나 사용 중지이면 복구만. 그 외 사용 중 계정은 초기화·삭제도 있다.
- 본인 행은 잠금·휴면·해제·삭제·초기화·역할 편집을 숨기고 안내를 보인다. 버튼은 비활성으로 두지 않는다.
- 역할 탭은 처음 열 때 한 번 조회한다. 편집은 사용 중 부여를 채워 보여주고, 저장은 선택 전체를 보낸다. 뺀 역할은 철회된다는 안내가 있다.

## 오류

- 서버 `errorMessage`가 있으면 그것을 쓴다.
- `USER.DUPLICATE_LOGIN_ID`는 로그인 아이디 칸, `USER.PERSON_ALREADY_LINKED`는 사람 칸.
- `USER.LAST_ADMIN`, `USER.SELF_OPERATION_FORBIDDEN`, `USER.INVALID_STATUS_TRANSITION`, `USER.NO_PASSWORD_ACCOUNT`는 안내 문구.
- `ROLE.INACTIVE`의 필드가 `roleCode`뿐이면 어느 행인지 알 수 없어 편집 창 안내에 보인다. 필드가 역할 코드면 그 행 옆에 보인다.
