# 언어·국가 관리 수동 확인

테넌트 앱(`npm run dev`)으로 로그인한다. 주소, 계정, 비밀번호는 여기에 적지 않는다. 백엔드를 먼저 띄운다.

아래만 직접 본다. 나머지 화면 흐름은 `src/pages/mdm/language/flow.test.tsx`와 `src/pages/mdm/i18n/flow.test.tsx`가 목으로 확인한다.

- 언어·국가 등록, 수정, 사용 중지, 복구가 실제 서버에 반영되는지
- 서버가 돌려준 오류 문구가 화면에 그대로 보이는지
- 좁은 화면에서 표와 Drawer가 쓸 수 있는지
- 언어를 바꾸거나 중지한 뒤 로그인·헤더 언어 선택에 반영되는지
- 화면을 써 본 전체 사용감

1. 지원 언어 목록은 `useYn` 없이 부르고, 사용 중지 행은 흐리며 복구 버튼이 있다. 자동 테스트: `flow.test.tsx`의 `loads languages without a use flag and shows restore on an inactive row`
2. 언어 등록, 수정 시 코드 읽기 전용, 기본 언어 변경 확인, 기본 행에는 중지가 없고 대체 언어에 자기 자신이 없다. 자동 테스트: `creates a language`, `keeps the language code read-only when editing`, `asks before replacing the default language`, `hides disable on the default language and omits that language from fallback choices`
3. 중지 확인과 취소, 409 서버 문구와 빈 문구, 400 순환, 저장 연타 1회. 자동 테스트: `explains disable and skips the call on cancel`, `shows the server conflict message`, `uses the local conflict text when the server message is empty`, `shows a fallback cycle message`, `sends one create while the request is in flight`
4. 저장 후 이 화면 목록은 다시 부르지만 언어 목록 캐시 무효화 호출은 없다. 자동 테스트: `reloads languages after save and does not call a cache invalidator`. 로그인·헤더 반영은 직접 확인
5. 국가 탭은 `?tab=nation`으로 유지되고, 서버 페이징·정렬을 부른다. 자동 테스트: `puts the nation tab in the query and opens it from the query`, `pages and sorts nations on the server`
6. 국가 코드 대문자, 형식 위반 시 저장 안 함, 수정 시 코드 읽기 전용, 기본 언어는 활성 언어만. 자동 테스트: `uppercases a nation code and blocks an invalid code`, `keeps the nation code read-only and offers only active languages`
7. 국가 논리 삭제·복구와 재조회, 409, 400 필드 오류, 403 안내, 목록 실패 시 탭 유지. 자동 테스트: `explains logical delete and reloads after disable`, `reloads after a confirmed nation disable and after restore`, `shows the server duplicate message`, `shows a field error under the input`, `shows a permission notice when the nation list is forbidden`, `keeps the tab when a later nation list fails`
8. 메시지 표는 목록 요약의 누락 언어를 경고 태그로 보여주고, 요약이 없으면 `—`이며 행마다 단건 조회를 하지 않는다. 자동 테스트: `src/pages/mdm/i18n/flow.test.tsx`의 `shows missing language tags from the list summary and does not load each message`, `shows a dash when the list has no translation summary`
9. 좁은 화면 배치. 직접 확인 필요
10. 플랫폼 콘솔에는 이 화면이 없다. `build:platform` 산출물에 `mdm/language`가 없고 `tenants`가 있다

규칙 자동 테스트: `src/pages/mdm/language/rules.test.ts`의 `normalizes and checks a nation code`, `builds a language body and drops blank optional fields`, `builds a nation body with an uppercased code`, `prefers the server error text and falls back to the local text`, `omits an empty language filter and sends nation page sort`, `drops the current language and inactive languages from fallback choices`
