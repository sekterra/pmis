# F5 서버 메뉴와 권한

화면 레이아웃은 바꾸지 않는다. 사이드 메뉴만 서버 `menus/my`로 채우고, 버튼과 주소 진입은 같은 응답의 `actions`로 가른다. 플랫폼 콘솔은 정적 메뉴 그대로다.

```
사이드 메뉴
  시스템                 서버 menuName (GROUP, 하위 화면이 있을 때만)
    다국어               I18N primary, 서버 menuName, /mdm/i18n
    언어·국가            I18N 두 번째 화면, 로컬 이름, /mdm/language
    공통코드             COMMON_CODE primary, 서버 menuName, /mdm/common-code
  환영                   서버 메뉴와 무관하게 항상 표시

메뉴를 불러오지 못함
  [다시 시도]
```

회사·부서처럼 표에 없는 메뉴는 숨긴다. 그룹 아래 화면이 하나도 없으면 그룹도 숨긴다. 비밀번호 변경과 예외 화면은 메뉴가 아니다.

| 상태 | can() | 표에 있는 주소 |
| --- | --- | --- |
| 로딩 전, 로딩 중, 실패 | 전부 false | 로딩은 스피너, 실패는 다시 시도. 화면 내용은 먼저 그리지 않는다 |
| 메뉴 있음, actions에 동작 있음 | true | READ가 있으면 화면, 없으면 403 |
| 메뉴 없음 | false | 403 |
| 환영, 로그인, 비밀번호, 예외 | 가드 없음 | 통과 |

로딩 시점: 로그인 후 me 다음, 세션 복구 후, 언어 변경 후, 비밀번호 변경 성공 후. 비밀번호 변경이 강제된 동안에는 호출하지 않는다. 로그아웃·401 로그인 이동·다른 탭 로그아웃이면 메모리의 메뉴를 비운다. 브라우저 저장소에는 메뉴와 Access 토큰을 넣지 않는다.
