# 다국어 관리 화면 (네임스페이스 / 메시지)

테넌트 앱 `/mdm/i18n`. 플랫폼 라우트에는 넣지 않는다. 지원 언어·국가 관리는 이 화면에 없다.

```
+---------------- 네임스페이스 ----------------+---------------- 메시지 ----------------+
| 검색                                        | 선택 전: 왼쪽에서 네임스페이스를 고르세요 |
| 사용 여부 [조회] [네임스페이스 등록]         | 선택 후: 코드, 이름, 설명                 |
| 표: 코드, 이름, 사용 여부, 수정/중지/복구    | 검색, 메시지 유형, 번역 상태, 사용 여부    |
| 사용 중지 행은 흐리게                        | [메시지 등록]                              |
| 페이지 20                                    | 표: 키, 기본 문구, 유형, 번역 상태, 사용 여부, 수정/삭제/복구 |
|                                             | 페이지 20                                  |
+---------------------------------------------+------------------------------------------+
```

좁은 화면에서는 메시지 표가 네임스페이스 아래로 내려간다. 행을 고르면 주소가 `?ns=코드`가 되고, 새로고침해도 그 네임스페이스 메시지를 다시 불러온다.

네임스페이스 Drawer: 코드(수정 시 읽기 전용), 이름, 솔루션 코드, 설명. 사용 중지 확인창에는 메시지는 남고 번들 조회에서 빠진다고 적는다.

메시지 Drawer 탭 [기본 정보] [언어별 번역]. 기본 정보: 네임스페이스(읽기 전용), 메시지 키(수정 시 읽기 전용), 유형(공통코드 `I18N_MESSAGE_TYPE`이 있으면 선택, 없으면 입력), 기본 문구, 파라미터 설명. 언어별 번역: 활성 언어마다 문구, 번역 상태(`I18N_TRANSLATION_STATUS` 선택), 기계 번역 여부. 문구가 빈 언어는 요청에서 뺀다. 기본 언어는 표시만 달리 한다. 수정 시 기존 `versionNo`는 읽기 전용이다.

번역 상태 열은 자리를 두되, 목록 응답의 `translations`가 비어 있어 빠진 언어를 계산하지 않는다. 단건 조회에만 번역이 있다.
