# F14 수동 확인 절차

값(주소, 계정, 비밀번호, 티켓)은 적지 않습니다. 각 항목은 템플릿 table-list / basic-form과 비교해 어색한 점이 있으면 적어 주세요.

1. 플랫폼 로그인
2. 테넌트 목록 — 검색(코드·이름·상태)·정렬·페이지. 템플릿 table-list과 비교해 어색한 점이 있으면 적어 주세요.
3. [테넌트 등록] — 폭(최대 720), 섹션, 도메인 추가·삭제, 취소. 템플릿 basic-form과 비교해 어색한 점이 있으면 적어 주세요.
4. 등록 → 임시 비밀번호 모달 → 닫기 → 상세
5. 지원 접속 기록(플랫폼) — 검색·기간·행 클릭 Drawer. 템플릿과 비교해 어색한 점이 있으면 적어 주세요.
6. 테넌트에 지원 접속한 뒤 테넌트 쪽 접속 기록(테넌트 코드 검색 없음) — 비교해 어색한 점이 있으면 적어 주세요.
