# F12 와이어프레임 (텍스트)

## 1. 플랫폼 테넌트 상세 — [테넌트 접속] 모달

- ACTIVE일 때만 액션바에 [테넌트 접속] 표시. 그 외는 숨기고 "ACTIVE 테넌트만 접속할 수 있습니다" 툴팁.
- 1단계: 사유 TextArea(선택, 200자), 안내 "비워 두면 접속 일시와 담당자 ID가 기록됩니다", 주의 문구, [접속 준비] / [취소].
- 2단계: [새 탭에서 열기] 링크(`target=_blank`), 남은 초(60→0), 0이면 링크 비활성 + [다시 발급]. 링크를 누른 뒤 닫기 가능. 닫으면 accessUrl 상태 삭제.

## 2. `/support-access` 진입 (레이아웃 없음)

- `#ticket=` 즉시 주소창에서 제거. `?tenant=`는 dev에서만 X-Tenant-Code.
- 상태: 로딩 / 티켓 없음 안내 / 교환 실패 안내 / 성공 시 `/`로 replace.

## 3. 지원 접속 띠

- 화면 최상단 고정: "지원 접속 중 · {operatorLoginId} · 남은 시간 mm:ss" + [지원 접속 종료].
- 5분 이하 강조. 0이면 종료 화면. 확인 후 end API → 토큰 삭제 → 종료 화면.

## 4. 기록 목록 (플랫폼 `/support-accesses`, 테넌트 `/access/support-access`)

- 필터: (플랫폼만 테넌트 코드), 운영자 로그인, 상태, 기간.
- 열: (플랫폼만 테넌트), 운영자, 사유(+자동), 상태 태그, 시작, 종료/만료, IP, 쓰기 수.
- 행 클릭 → Drawer: 요약 + 쓰기 요청 목록(시각, 메서드, 경로, 코드, 민감).

## 5. 종료 화면 `/support-access/ended`

- "지원 접속이 종료되었습니다" / "이 탭을 닫아도 됩니다" / 다시 접속은 플랫폼 콘솔 안내.
