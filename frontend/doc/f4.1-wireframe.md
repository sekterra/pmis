# F4.1 언어·국가 관리 와이어프레임

합의된 화면이다. 등록과 수정은 오른쪽 Drawer다. 탭은 `?tab=language` 또는 `?tab=nation` 이고 새로고침 후에도 유지된다.

```
[언어·국가 관리]                                     ?tab=language | nation
 ┌ [지원 언어] [국가] ──────────────────────────────────────┐
 │ (지원 언어 탭)                                            │
 │  사용 여부 필터 [전체▾]                  [언어 등록]       │
 │  코드 | 언어명 | 현지 표기 | 기본 | 대체 언어 | 방향 |    │
 │       | 정렬 | 사용 | 동작[수정][사용 중지|복구]            │
 │ (국가 탭)                                                 │
 │  검색 [keyword] 사용 여부 [전체▾]        [국가 등록]       │
 │  국가 코드 | 국가명 | 기본 언어 | 정렬 | 사용 | 동작       │
 │  서버 페이징(페이지 20)                                    │
 └───────────────────────────────────────────────────────────┘
```

국가 목록 API(`GET /nations?managed=true`)에는 `keyword`와 `useYn`이 없다. 그 두 필터는 화면에 만들지 않는다. 국가 표의 열, 페이징, 정렬, 등록 Drawer는 둔다.
