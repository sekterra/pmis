# F8 부서 화면

기준: `frontend/doc/org-screens-wireframe.md` 1절·3절. 화면 구성은 그 문서와 같다. F8 지시가 행 이동을 빼라고 한 점만 다르다.

## 상단

- 회사 Select: 사용 중 회사. 없으면 "회사를 먼저 등록하세요." 기본값은 목록의 첫 회사. 선택은 `?company=` 에 둔다.
- 기준일: 기본 오늘. 비우면 서버 기본(파라미터 생략).
- "종료된 부서 포함", [조회].

## 트리

- `GET /departments/tree` 전위 순회를 `deptPath` 로 중첩한다. 부모가 결과에 없으면 최상위. 순서는 유지한다.
- 표시: 부서명 + 코드. 종료된 부서는 회색과 "종료".
- 기본 펼침은 1레벨(2레벨이 보이게). 선택한 부서의 조상은 펼친다.
- 선택은 `?dept=` 에 둔다.
- 아래 [최상위 부서](`CREATE`). 부서가 없으면 "최상위 부서를 등록하세요."

## 오른쪽

- 선택 전: "부서를 선택하세요."
- [하위 부서 추가](`CREATE`, 종료된 부서에는 숨김), [수정](`UPDATE`), [종료](`DELETE`). 종료된 부서는 [재개](`UPDATE`).
- 기본 정보: 코드, 회사, 유형 이름, 상위 부서, 유효기간, 레벨, 정렬, 이름 번역, 사용 여부. 상세 API.
- 변경 이력: 서버 페이징. 변경 유형 문구, 적용일, 이름 전→후, 상위 부서 PK 전→후, 사유, 변경 시각. 수정·삭제 없음. 상위 이름은 조회 API가 없어 PK만 보인다. 탭을 처음 열 때와 부서가 바뀔 때 호출한다.
- 소속 인원: `GET /people?deptPk=`. 이름, 직위, 재직 상태. 주 소속 안내. 행 클릭 이동은 만들지 않는다. `PERSON:READ` 가 없으면 탭은 있고 "조회 권한이 없습니다."

## Drawer

- 부서 코드(등록만, 50자 이내), 회사(상단 값, 읽기 전용), 부서명(필수), 유형(`DEPT_TYPE`), 상위 부서(사용 중, 수정 시 자기·하위 불가, 하위 추가로 열면 미리 채움), 정렬, 유효 시작(등록 기본 오늘), 유효 종료(시작일 이상), 이름 번역.
- 수정에서 이름 또는 상위가 바뀌면 적용일(기본 오늘)과 변경 사유. 둘 다 바뀌면 이력이 두 줄이라는 안내. 바뀌지 않으면 보내지 않는다.
- 화면에 없는 설명은 수정 때 상세 값을 다시 보낸다.
- 종료 확인: "종료일이 오늘로 설정되고 이력이 남습니다."

## 오류

| 코드 | 표시 |
| --- | --- |
| `fieldErrors` | 해당 입력칸 |
| `DEPT.DUPLICATE` | 부서 코드 |
| `DEPT.PARENT_CYCLE`, `PARENT_COMPANY_MISMATCH`, `PARENT_INACTIVE` | 상위 부서 |
| `DEPT.INVALID_DATE` | 유효 종료일 |
| `DEPT.HAS_CHILD`, `HAS_ACTIVE_ASSIGNMENT` | 종료 거절 알림. 서버 메시지 |
| `DEPT.PARENT_INACTIVE` 복구 | 재개 거절 알림. 서버 메시지 |
| 그 밖 | 서버 `errorMessage`. 없으면 로컬 문구 |
