# F6 직접 확인

값은 적지 않는다. 비밀번호, 토큰, 계정은 이 문서에 두지 않는다.

1. `DEV_TENANT_CODE`를 둔 뒤 같은 `/user/login`에서 테넌트 관리자와 일반 사용자로 로그인한다. 화면은 같고 사이드 메뉴만 다르다.
2. `DEV_TENANT_CODE`를 비우고 플랫폼 운영자로 로그인한다. 사이드 메뉴는 "테넌트 관리" 하나다.
3. 플랫폼으로 로그인한 뒤 주소에 `/mdm/language`를 입력하면 403이다.
4. 비밀번호 변경이 필요한 계정은 `/user/password`로 간다.
5. 백엔드를 끈 뒤 화면을 열면 "서버에 연결할 수 없습니다"가 보이고 로그인 폼은 없다.
